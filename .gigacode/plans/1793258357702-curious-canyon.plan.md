# Plan: LSTM Multi-Output Refactor (20 outputs = 5 candles × OHLC)

## Goal
Change LSTM from single close_return prediction to 5-candle OHLC prediction (20 outputs). Remove autoregression at predict time — single forward pass produces all 20 values. Update all tests.

## Constants
```c
#define PREDICTION_HORIZON 5
#define OUTPUTS_PER_CANDLE 4   /* OHLC */
#define NUM_OUTPUTS (PREDICTION_HORIZON * OUTPUTS_PER_CANDLE)  /* 20 */
```

## Files to modify (in order)

### 1. `include/lstm.h`
- Add constants `PREDICTION_HORIZON`, `OUTPUTS_PER_CANDLE`, `NUM_OUTPUTS`
- Add `int num_outputs` field to `LSTMNetwork`
- Change `weight_output_layer` to `Matrix *` [num_outputs × num_cells]
- Change `bias_output_layer` to `double *` [num_outputs]
- Same for gradient fields (`dweight_output_layer`, `dbias_output_layer`) and momentum (`mweight_output_layer`, `mbias_output_layer`)
- `lstm_init` signature: add `int num_outputs` param
- `lstm_forward` → `void lstm_forward(..., double *outputs)` (fills outputs[0..num_outputs-1])
- `lstm_backward` → takes `const double *predictions, const double *targets` (arrays of num_outputs)
- `lstm_predict` → `void lstm_predict(..., double *outputs)`
- `lstm_compute_loss`, `lstm_compute_accuracy` signatures unchanged

### 2. `src/lstm.c`
- **`lstm_init`**: allocate output layer as [num_outputs × num_cells], bias as `double[num_outputs]`. Same for gradients and momentum. Store `num_outputs`.
- **`lstm_free`**: free arrays (`free(net->bias_output_layer)`, etc.)
- **`lstm_forward`**: after LSTM loop, compute all outputs:
  ```c
  for (o = 0; o < num_outputs; o++) {
      double sum = net->bias_output_layer[o];
      for (c = 0; c < n; c++)
          sum += W_out[o * n + c] * hidden_state[c];
      outputs[o] = sum;
  }
  ```
  Return type changes to `void`.
- **`lstm_zero_gradients`**: zero all `num_outputs * n` gradient elements and `num_outputs` bias grads
- **`lstm_backward`**: 
  ```c
  double d_logit[MAX_OUTPUTS];
  for (o = 0; o < num_outputs; o++) {
      d_logit[o] = predictions[o] - targets[o];
      for (c = 0; c < n; c++)
          dweight_output_layer[o * n + c] += d_logit[o] * last_hidden[c];
      dbias_output_layer[o] += d_logit[o];
  }
  for (c = 0; c < n; c++) {
      dhidden[c] = 0.0;
      for (o = 0; o < num_outputs; o++)
          dhidden[c] += d_logit[o] * W_out[o * n + c];
  }
  ```
  Rest of BPTT unchanged.
- **`lstm_update`**: update all `num_outputs * n` weights and `num_outputs` biases (loops over num_outputs)
- **`lstm_compute_loss`**: `loss = sum over all num_outputs of 0.5*(pred-label)^2`, averaged by num_samples. Allocate `double *preds` buffer.
- **`lstm_compute_accuracy`**: average direction accuracy across all num_outputs outputs
- **`lstm_predict`**: allocate cell_states, call `lstm_forward` with output buffer, free. Signature: `void lstm_predict(..., double *outputs)`

### 3. `include/data.h`
- Add `int num_outputs` to `Dataset`
- Change `double *labels` to `double **labels`
- Change `double label_min, label_max` to `double *label_min, *label_max`
- `data_build_dataset` signature: add `int prediction_horizon` param

### 4. `src/data.c`
- **`data_build_dataset`**: 
  - `num_outputs = prediction_horizon * 4`
  - `num_samples = num_raw - seq_len - prediction_horizon` (need 5 future candles)
  - Allocate `labels` as `double **` (num_samples arrays of num_outputs)
  - Allocate `label_min`, `label_max` as `double[num_outputs]`
  - For each sample i:
    - `ref_close = raw[i + seq_len - 1].close`
    - For k=0..PREDICTION_HORIZON-1:
      - `target_idx = i + seq_len + k`
      - `labels[i][k*4+0] = (raw[target_idx].open - ref_close) / ref_close`
      - `labels[i][k*4+1] = (raw[target_idx].high - ref_close) / ref_close`
      - `labels[i][k*4+2] = (raw[target_idx].low - ref_close) / ref_close`
      - `labels[i][k*4+3] = (raw[target_idx].close - ref_close) / ref_close`
    - Track per-output min/max
- **`data_normalize`**: per-output symmetric scaling (divide by max_abs per output)
- **`data_free_dataset`**: free each `labels[i]`, then `labels`; free `label_min`, `label_max`
- **`data_split_train_test`**: copy `double*` pointers for labels (shallow copy)
- **`data_save_normalization`** / **`data_load_normalization`**: write/read `num_outputs` label_min/label_max values

### 5. `src/model.c`
- **`model_save`**: 
  - Output layer section: write `num_outputs` rows, each `num_cells` weights
  - Bias: write `num_outputs` values
  - Add `num_outputs` to metadata
- **`model_load`**:
  - Parse `num_outputs` from metadata (or use net->num_outputs)
  - Load `num_outputs × num_cells` weight matrix
  - Load `num_outputs` bias values
  - Normalization: load `num_outputs` label_min/label_max

### 6. `main.c`
- **Training mode**:
  - `lstm_init(num_lstm_cells, num_features, NUM_OUTPUTS, seed)`
  - `data_build_dataset(raw_data, num_raw, sequence_length, PREDICTION_HORIZON)`
  - Allocate `double preds[NUM_OUTPUTS]` buffer
  - Training loop: `lstm_forward(..., preds)`, `lstm_backward(..., preds, train->labels[idx], seq_len)`
  - Loss computation: MSE over all 20 outputs
- **Prediction mode** (complete rewrite):
  - Load model, load normalization
  - Compute features for last `seq_len` candles
  - Normalize
  - Single `lstm_predict(..., preds)` call → 20 values
  - Denormalize: convert returns to OHLC prices using `ref_close`
  - Output 5 candles: `PRE [k] O H L C`
  - NO autoregression, NO extended features, NO clipping
- **Real data mode**: unchanged
